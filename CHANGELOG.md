# Changelog

## 1.0.0 — 2026-11-12

Initial source implementation: native management panel and launch menu, per-host visibility/order/defaults/permissions, Space defaults, launch profiles, parameters/models/environment/shortcuts, custom commands, permission adapters, launch review and stale-target checks, import/export/recovery, CLI diagnostics, non-destructive install/upgrade/uninstall, generated Mods, tests and cross-platform CI.

Native desktop acceptance remains required (docs/VALIDATION.md). The source version is not a claim of a published GitHub Release or native certification.
